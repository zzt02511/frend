# 口播视频 AI 自动精剪设计

## 背景

当前项目已经具备两条相关能力：

- `3D/ai-ip-content-pack-tool` 已验证门业/建材一周内容包生成、剪辑指令和交付文档导出。
- `KrLongAI-master` 已具备定制家居获客内容生成、真实素材管理、项目保存、数字人任务提交和内容流水线导出。

新的功能目标是把“剪辑指令”推进到“可发布成片草稿”：用户上传一段真人口播视频，再上传产品、工厂、案例、门店等真实素材，系统生成可编辑的 AI 剪辑方案，用户确认后由 FFmpeg 自动渲染 MP4。

## 产品定位

第一版功能暂定名为 **口播视频 AI 自动精剪**。

核心价值：

> 把代运营从“拿着口播和素材手动剪片”变成“上传口播和素材，先得到可编辑剪辑方案，再一键渲染获客短视频草稿”。

它不是完整网页剪辑器，也不是全自动替代剪辑师。第一版优先保证：

- 输入真实口播视频和真实素材。
- 输出可解释、可编辑的剪辑方案。
- 输出一个可发布或可二次微调的竖屏 MP4 草稿。
- 遇到素材、转写、BGM、FFmpeg 等问题时可降级，不中断整条交付链路。

## 已确认决策

- 输入类型选 **口播视频 + 产品/工厂/案例/门店素材**。
- 口播文字稿支持 **用户提供脚本优先，缺脚本时尝试语音转写**。
- 产品形态选 **两级模式：先生成可编辑剪辑方案，再渲染 MP4**。
- 发布规格默认面向小红书/抖音竖屏，比例可选，默认 `9:16`。
- 剪辑引擎路线选 **先 FFmpeg 自动出片，后续再考虑剪映草稿导出**。
- 第一版放进 `KrLongAI-master`，复用现有 `custom_home_server.py`、素材上传、项目保存和内容流水线能力。
- 运行路线选 **先本地 Windows 跑通，后续再扩展云端**。
- 第一版效果范围选 **精剪草稿**：删停顿、字幕、标题、素材穿插、转场、BGM、音效、关键词高亮、封面图、进度条和片尾 CTA。
- 素材匹配选 **人工标签 + AI 辅助建议**，用户可以修改标签。
- 实现路线选 **AI 剪辑方案 + FFmpeg 渲染**。

## 用户流程

1. 用户打开 `KrLongAI-master` 的本地工作台。
2. 用户上传一段真人口播视频。
3. 用户可选上传或粘贴口播脚本；缺脚本时系统尝试语音转文字。
4. 用户上传或选择产品、工厂、安装案例、门店、客户空间等真实素材。
5. 用户给素材打标签；系统可以根据文件名、备注和可用 AI 能力给出标签建议。
6. 系统分析口播视频、脚本和素材标签，生成 `edit_plan.json`。
7. 用户在页面上查看并编辑剪辑方案关键字段。
8. 用户点击渲染。
9. 系统调用 FFmpeg 输出 MP4、字幕文件、封面图和渲染日志。
10. 成片后续可以进入发布包或交付包。

## 系统模块

### talking_video_editor.py

负责生成剪辑方案。

职责：

- 读取口播视频元信息。
- 根据脚本或转写文本生成口播分段。
- 根据素材标签和段落关键词匹配 B-roll 素材。
- 生成标题、CTA、关键词高亮、封面建议和渲染设置。
- 输出稳定的 `edit_plan.json`。

第一版可先使用本地规则生成可用方案；当配置了 OpenAI 兼容接口或其它模型时，可以用 AI 优化分段、标题、关键词和素材匹配。

### ffmpeg_video_renderer.py

负责根据 `edit_plan.json` 渲染视频。

职责：

- 生成并执行 FFmpeg 命令。
- 裁切或适配竖屏画面。
- 删除长静音或停顿片段。
- 叠加字幕、标题、CTA、进度条和关键词高亮。
- 按剪辑方案覆盖 B-roll 素材，同时保留口播声音主线。
- 混入 BGM 和轻量音效，并对人声做 ducking。
- 导出 MP4、字幕文件、封面图和日志。

### custom_home_server.py

新增本地 API。

建议接口：

- `POST /api/talking-video/projects`
- `GET /api/talking-video/projects`
- `GET /api/talking-video/projects/<project_id>`
- `DELETE /api/talking-video/projects/<project_id>`
- `POST /api/talking-video/assets`
- `POST /api/talking-video/plan`
- `POST /api/talking-video/render`
- `GET /api/talking-video/render/<task_id>`

### talking_video_editor.html

新增本地工作台页面。

职责：

- 上传口播视频、脚本和素材。
- 管理素材标签。
- 展示剪辑方案。
- 允许用户编辑标题、CTA、段落文本、素材穿插、字幕样式和输出设置。
- 发起渲染并查看结果。

### talking_video_projects/

保存每个剪辑项目。

建议结构：

```text
talking_video_projects/<project_id>/
  project.json
  edit_plan.json
  uploads/
    talking.mp4
    assets/
  captions/
  renders/
    final.mp4
    cover.jpg
  logs/
    ffmpeg.log
```

真实用户视频、音频、素材和成片不得提交到 git。

## 数据流

```text
口播视频 + 可选脚本 + 素材文件/标签
        ->
媒体探测：时长、尺寸、音轨、静音段
        ->
脚本或转写文本分段
        ->
素材标签匹配：产品/工厂/案例/门店/细节
        ->
AI 剪辑方案 JSON
        ->
用户确认或编辑
        ->
FFmpeg 渲染任务
        ->
MP4 + 字幕文件 + 封面图 + 发布说明
```

## 剪辑方案数据模型

剪辑方案保存为 `edit_plan.json`，作为后续 FFmpeg、剪映草稿或云端渲染的稳定中间层。

```json
{
  "projectId": "talking-video-001",
  "sourceTalkingVideo": "uploads/talking.mp4",
  "aspectRatio": "9:16",
  "durationTarget": 60,
  "scriptSource": "user-script",
  "segments": [
    {
      "id": "seg-001",
      "start": 0.0,
      "end": 6.8,
      "text": "这一段口播字幕",
      "intent": "开场痛点",
      "keywords": ["装修", "入户门"],
      "brollSlots": [
        {
          "startOffset": 2.0,
          "duration": 3.0,
          "assetId": "asset-product-detail",
          "reason": "匹配关键词：入户门"
        }
      ]
    }
  ],
  "captions": {
    "style": "bold-bottom",
    "highlightKeywords": true
  },
  "overlays": {
    "title": "装修选门别只看价格",
    "cta": "评论区回复户型，发你选门清单",
    "progressBar": true
  },
  "audio": {
    "bgm": "light-commercial",
    "ducking": true,
    "soundEffects": ["whoosh-soft"]
  },
  "cover": {
    "text": "选门避坑清单",

  },
  "render": {
    "output": "renders/final.mp4",
    "status": "draft"
  }
}
```

## 第一版剪辑效果

包含：

- 自动删静音和长停顿，保留自然停顿。
- 默认竖屏 `9:16`，支持用户选择其它比例。
- 自动字幕。
- 关键词高亮。
- 口播声音不断，B-roll 素材覆盖画面。
- 产品、工厂、案例、门店素材按标签插入。
- 标题贴片。
- 片尾 CTA。
- 轻量转场。
- BGM 自动压低人声。
- 简单音效。
- 进度条。
- 封面帧或封面图导出。

不包含：

- 复杂时间线拖拽编辑。
- 多轨专业剪辑器。
- 自动发布。
- 完整剪映草稿导出。
- 高级人像抠图或美颜。
- 复杂 AI 视频生成。

## 错误处理和降级

### 缺少脚本

系统尝试语音转文字。转写不可用时，提示用户手动粘贴脚本；系统仍保留项目和已上传素材。

### 缺少转写能力

使用用户脚本和整段口播视频生成分段方案。无法精确对齐时，按平均时长或静音点近似分段，并提示用户检查。

### 素材标签不足

系统根据文件名、备注、素材类型和可用 AI 能力给出标签建议，并提示用户补充或修正。

### B-roll 素材不足

减少穿插次数，保留口播主画面，不编造素材，不生成虚假案例。

### BGM 或音效缺失

跳过 BGM 或音效，不影响字幕、标题、CTA 和主视频渲染。

### FFmpeg 不存在

生成剪辑方案和 FFmpeg 命令，但不执行渲染。页面明确提示安装 FFmpeg，并保留可复制命令。

### 渲染失败

保留 `edit_plan.json`、字幕文件、FFmpeg 命令和 `ffmpeg.log`，允许用户修正后重试。

### 视频比例不合适

优先居中裁切；如果裁切会明显损失主体，则使用模糊背景或留边适配。

### 口播过长

给出 30 秒、60 秒、90 秒版本建议。第一版不强行破坏语义乱剪。

## MVP 范围

### 包含

- 本地工作台入口。
- 上传口播视频、脚本和真实素材。
- 人工素材标签和系统标签建议。
- 生成可编辑 `edit_plan.json`。
- 渲染竖屏 MP4。
- 导出字幕、封面图和日志。
- 缺素材、缺 BGM、缺 FFmpeg 时明确降级。
- 单元测试覆盖核心方案生成和命令生成。

### 不包含

- 云端多人队列。
- 自动发布到小红书、抖音或视频号。
- 复杂 CRM。
- 剪映草稿导出。
- 完整浏览器剪辑器。
- 自动识别所有素材内容并保证准确。
- 数字人生成。
- 大模型强依赖。

## 验收标准

给定：

- 一段真人口播视频。
- 一份口播脚本，或可用转写文本。
- 5-10 个带标签或备注的真实素材。

系统应能：

- 生成 `edit_plan.json`。
- 剪辑方案包含口播分段、字幕、标题、CTA、素材穿插点和输出设置。
- 页面展示并允许编辑剪辑方案关键字段。
- 渲染出一个 MP4。
- 默认输出竖屏 `9:16`。
- 输出视频包含字幕、标题、至少 2 段素材穿插和片尾 CTA。
- BGM、音效或素材不足时仍能降级输出。
- FFmpeg 不可用时明确提示，并保留方案和可复制命令。
- 测试覆盖剪辑方案生成、素材匹配、缺素材降级和 FFmpeg 命令生成。
- `.gitignore` 排除用户真实视频、音频、素材、项目包和渲染结果。

## 后续阶段

第二阶段可以加入：

- 更准确的语音识别和字级时间戳。
- AI 视觉识别素材并自动打标签。
- 可视化时间线微调。
- 剪映草稿导出。
- 云端渲染队列。
- 多客户剪辑任务看板。
- 视频数据复盘。
- 自动发布或半自动发布。

这些能力应在第一版证明“口播 + 素材 -> 可编辑方案 -> MP4 草稿”的闭环后再加入。

# AI-IP 口播视频自动化项目需求草稿

## 1. 项目概述

项目名称：AI-IP

AI-IP 是一款面向老板、创始人和实体商家负责人的口播视频自动化 App，帮助用户完成从 IP 资料沉淀、爆款文案生成、透明提词拍摄、自动剪辑包装、成片预览到发布的完整流程。

第一版产品不做销售管理系统，不做 CRM，不做企业组织管理。核心目标是帮助老板个人更轻松、稳定地产出可发布的口播视频。

一句话定位：

让老板输入一个主题，就能生成适合自己的口播文案，照着手机提词拍摄，拍完自动剪辑成片，并发布到短视频平台。

## 2. 目标行业与目标用户

目标行业：

- 有 IP 打造需求的实体商家
- 新媒体创业者
- 想通过老板出镜建立信任感的品牌方
- 有产品、服务、案例和成交经验，但缺少内容生产能力的商家

第一版核心用户：

- 老板
- 创始人
- 实体商家负责人
- 个人 IP 起步者

典型用户：

- 门店老板
- 工厂老板
- 装修、家居、建材、美业、教育培训等行业负责人
- 想通过短视频获客、招商、成交、建立信任的新媒体创业者

## 3. 产品边界

AI-IP 第一版只做老板个人 IP 口播视频自动化。

保留范围：

- 微信登录和手机号验证码登录
- 老板 IP 档案
- 每个用户独立 RAG 知识库
- 产品图片理解
- AI 爆款口播文案生成
- 文案手动编辑
- 手机透明提词拍摄
- 拍摄中切换前后镜头
- 拍摄亮度和自然美颜优化
- 自动剪辑包装
- 剪辑进度展示
- 成片元素自定义
- BGM 选择、上传和音量调节
- 成片预览
- 发布到抖音、视频号、小红书
- “看看别人怎么拍”案例与实时聊天

明确不做：

- 销售团队管理
- 经销商管理
- 客户管理 CRM
- 跟进记录
- 企业微信通知
- Agent Tool API
- 完整知识库问答
- 企业组织架构和复杂权限
- 多账号矩阵发布
- 数据看板和线索转化追踪

多租户设计只用于用户数据隔离，不扩展为企业管理系统。

## 4. 核心用户问题

AI-IP 要解决以下问题：

1. 老板不知道每天拍什么。
2. 老板不会写适合自己业务的短视频口播文案。
3. 老板拍摄时容易忘词、卡壳、表达不顺。
4. 手机自拍时需要透明提词，文案随口播进度滚动。
5. 提词字号、透明度、滚动速度需要可调。
6. 拍摄过程中需要切换前后摄像头，同时保证提词器和录音不中断。
7. 拍摄时光线可能不好，需要自动或手动调整亮度和自然美颜。
8. 拍完后不想手动剪辑，希望自动去口气词、去停顿、加字幕和重点黄字。
9. 自动剪辑过程中需要看到进度，否则用户不知道系统是否还在处理。
10. 成片中的 Logo、字幕、水印、片头、片尾、BGM 等元素需要可开关、可自定义。
11. 剪辑完成后，希望能尽量一键发布到抖音、视频号、小红书。
12. 用户希望能看看别人怎么拍，学习案例，也能像直播间一样交流使用方法。

## 5. 核心业务流程

主流程：

1. 用户打开 App。
2. 默认使用微信登录，也可以选择手机号验证码登录。
3. 首次登录后创建老板 IP 档案。
4. 用户录入或上传自己的业务素材，形成个人 RAG 知识库。
5. 用户上传产品照片，系统识别产品外观、文字、卖点和场景。
6. 用户输入本次口播主题。
7. AI 结合爆款口播结构、老板 IP 档案、RAG 知识库和产品图片生成口播文案。
8. 用户手动修改、局部改写或重新生成文案。
9. 用户进入拍摄准备页，设置提词字号、透明度、滚动速度、亮度、美颜和成片模板。
10. 用户进入透明提词拍摄页，边看提词边录制。
11. 拍摄过程中可切换前后摄像头，录音和提词不中断。
12. 拍摄结束后进入预览确认页。
13. 用户点击确认使用。
14. 系统自动进入剪辑状态，不要求用户手动上传或导入。
15. 剪辑进度页展示当前步骤、百分比和预计剩余时间。
16. 剪辑完成后进入成片预览页。
17. 用户可修改字幕、重点黄字、标题、封面、发布文案和话题标签。
18. 用户发布到抖音、视频号、小红书，或保存到本地。

“看看别人怎么拍”辅助流程：

1. 在文案页、拍摄准备页、拍摄页展示“看看别人怎么拍”按钮。
2. 用户点击后打开半屏浮层。
3. 上方展示优秀案例、爆款脚本拆解和拍摄技巧。
4. 下方展示实时聊天区。
5. 用户可以像直播间一样发送文字交流，消息上下滚动。

## 6. 功能模块

### 6.1 登录与账号模块

默认登录方式为微信登录。

功能要求：

- 用户可使用微信登录。
- 用户可使用手机号和验证码登录。
- 微信登录时请求授权，获取微信授权昵称、头像、OpenID 或 UnionID。
- 如果微信侧无法提供真实姓名，则使用微信授权昵称，并允许用户设置对外显示名。
- 用户可绑定手机号。
- 手机号登录用户可绑定微信。
- 每个新用户登录后自动创建个人数据空间。
- 社区聊天默认展示头像和显示名，不强制公开真实身份。

### 6.2 多租户数据隔离

每个用户拥有独立数据空间。

隔离内容：

- IP 档案
- RAG 知识库
- 产品图片
- 文案记录
- 拍摄记录
- 剪辑任务
- 成片模板
- 发布授权

多租户只用于数据隔离，不做企业组织架构、成员权限、团队管理。

### 6.3 老板 IP 档案模块

用于让 AI 理解用户是谁、卖什么、服务谁、怎么表达。

字段包括：

- 老板姓名或昵称
- 行业
- 品牌、门店或公司名称
- 产品或服务
- 目标客户
- 老板个人经历
- 品牌故事
- 典型成交案例
- 常见客户问题
- 表达风格
- 禁用词或不希望表达的内容

表达风格示例：

- 专业型
- 真实接地气型
- 强销售型
- 知识分享型
- 老板故事型

### 6.4 RAG 知识库模块

每个用户都有自己的 RAG 知识库，用于让文案更贴近真实业务。

素材来源：

- 手动录入
- 文档上传
- 产品资料
- 成交案例
- 客户痛点
- 常见问答
- 销售话术
- 品牌故事
- 过往优秀文案

功能要求：

- 用户可新增、修改、删除素材。
- 素材可按类型和标签管理。
- 系统可对素材建立向量索引。
- AI 生成文案时自动检索相关素材。
- 用户可查看本次文案参考了哪些素材。

### 6.5 产品图片理解模块

用户可以上传产品照片，AI 生成文案时结合图片内容和 RAG 知识库。

图片类型：

- 产品照
- 包装图
- 海报图
- 使用场景图
- 产品细节图

系统需要识别：

- 产品外观
- 颜色
- 材质
- 包装
- 使用场景
- 适合人群
- 图片中的文字
- 产品名
- 规格
- 卖点
- 价格或活动信息
- 品牌信息

产品图片参与生成：

- 生成口播文案
- 建议封面标题
- 建议画面重点
- 建议重点黄字
- 建议拍摄角度

### 6.6 AI 爆款文案生成模块

AI 生成文案时默认结合：

- 爆款视频文案结构库
- 用户个人 RAG 知识库
- 老板 IP 档案
- 产品图片理解结果
- 当前拍摄主题
- 目标平台
- 视频时长
- 表达风格

爆款结构示例：

- 痛点开场
- 反常识观点
- 老板故事
- 客户案例
- 产品对比
- 避坑提醒
- 成交理由
- 品牌信任
- 行业知识分享

功能要求：

- 用户输入主题后生成口播稿。
- 系统可推荐选题。
- 用户可选择视频时长。
- 用户可选择目标平台：抖音、视频号、小红书。
- 用户可选择表达风格。
- 用户可手动修改文案。
- 用户可重新生成。
- 用户可局部改写。
- 用户可缩短或扩写。
- 用户可调整语气。
- 用户可标记重点句，用于后续黄色字幕。

要求：

- 文案要像老板本人能说出口的话。
- 文案不能只是通用营销腔。
- 爆款文案结构只能作为结构参考，不直接复制他人原文。

### 6.7 透明提词拍摄模块

这是第一版的核心体验。

功能要求：

- 支持手机竖屏拍摄。
- 文案以透明状态显示在摄像头预览画面上。
- 支持调整提词字号。
- 支持调整提词透明度。
- 支持调整提词滚动速度。
- 支持调整提词位置。
- 支持手动速度滚动。
- 支持语音跟随滚动作为增强模式。
- 支持暂停、继续、重拍。
- 支持前后摄像头切换。
- 切换摄像头时录音不中断。
- 切换摄像头时提词状态不中断。
- 切换摄像头时已拍摄内容不中断。
- 拍摄结束后展示预览确认。
- 用户点击确认使用后自动进入剪辑状态。

### 6.8 拍摄亮度与自然美颜模块

拍摄过程中，系统需要让人物画面更清晰自然。

功能要求：

- 自动检测环境光线和人脸亮度。
- 光线偏暗时自动提升曝光、亮度或补光效果。
- 用户可手动调整亮度。
- 支持自然美颜。
- 美颜包含轻微磨皮、肤色优化、面部提亮。
- 美颜强度可调。
- 美颜可关闭。
- 前置和后置摄像头都支持亮度优化和美颜。

产品定位：

- 默认自然清晰，不做夸张滤镜。
- 老板 IP 画面要专业、干净、可信，不失真。

### 6.9 自动剪辑包装模块

拍摄完成后，用户点击确认使用，系统自动进入剪辑状态。

不能要求用户做以下多余动作：

- 手动上传视频
- 手动导入素材
- 手动选择刚拍好的视频文件

如果需要云端处理，上传应在后台自动完成，并在进度中显示处理状态。

剪辑能力：

- 语音识别
- 去口气词
- 去中间停顿和空档
- 自动字幕
- 重点内容黄色字幕
- 自动生成标题
- 自动生成封面
- Logo
- 水印
- 片头
- 片尾
- BGM
- 成片合成

成片元素需要支持显示或隐藏：

- Logo 可显示或隐藏
- 字幕可显示或隐藏
- 重点黄字可显示或隐藏
- 水印可显示或隐藏
- 片头可显示或隐藏
- 片尾可显示或隐藏
- BGM 可开启或关闭

### 6.10 BGM 模块

BGM 支持用户自定义。

功能要求：

- 用户可开启或关闭 BGM。
- 用户可调整 BGM 音量。
- 系统提供默认 BGM 库。
- 用户可自行挑选系统 BGM。
- 用户可上传自己的 BGM。
- 用户上传 BGM 时提示版权风险。
- 系统内置 BGM 应优先使用可商用或已授权音乐。
- 用户选择的 BGM 和音量可保存到默认成片模板。

BGM 风格示例：

- 商务专业
- 温暖信任
- 轻快日常
- 情绪故事
- 成交转化
- 小红书氛围感

默认建议：

- 人声优先。
- BGM 音量偏低，只做氛围，不盖住口播。

### 6.11 剪辑进度反馈模块

拍摄完成并确认后，用户进入剪辑进度页。

页面需要显示：

- 当前处理步骤
- 总进度百分比
- 预计剩余时间
- 处理中状态
- 失败原因
- 重新剪辑入口

剪辑步骤示例：

1. 正在处理视频
2. 正在识别语音
3. 正在去除口气词
4. 正在剪掉停顿
5. 正在生成字幕
6. 正在标记重点黄字
7. 正在生成标题和封面
8. 正在添加 Logo、水印、BGM、片头片尾
9. 正在合成成片
10. 剪辑完成

剪辑失败时：

- 显示失败原因。
- 支持重新剪辑。
- 支持保留原始视频。

### 6.12 成片模板模块

用户可保存自己的默认成片模板。

模板包含：

- Logo 文件
- Logo 显示开关
- 字幕显示开关
- 字幕样式
- 重点黄字显示开关
- 水印显示开关
- 水印位置
- 水印透明度
- 片头显示开关
- 片尾显示开关
- BGM 显示开关
- BGM 来源
- BGM 音量
- 封面样式

交互要求：

- 第一次设置后可保存为默认模板。
- 下次剪辑默认使用上次模板。
- 成片预览页可临时修改模板。
- 用户可选择是否将修改保存为默认。

### 6.13 成片预览与发布模块

剪辑完成后进入成片预览页。

用户可修改：

- 字幕
- 重点黄字
- 标题
- 封面
- 发布文案
- 话题标签
- Logo、字幕、水印、片头、片尾、BGM 显示开关
- BGM 音量

发布平台：

- 抖音
- 视频号
- 小红书

发布方式：

1. 平台 API 可用时，用户授权后直接发布。
2. 平台 API 受限时，使用发布助手：保存视频、复制标题、复制文案、复制话题标签、跳转平台 App。

### 6.14 看看别人怎么拍模块

入口名称：看看别人怎么拍

入口位置：

- 首页
- 文案生成页
- 拍摄准备页
- 拍摄页

点击后打开半屏浮层。

上半部分：

- 优秀口播案例
- 爆款脚本拆解
- 拍摄姿势参考
- 开场话术参考
- 封面标题参考
- 官方拍摄技巧
- 一键仿写同款脚本入口

下半部分：

- 实时聊天区
- 所有正在使用 AI-IP 的用户可发文字交流
- 消息像直播间一样上下滚动
- 支持官方置顶消息
- 支持基础敏感词过滤
- 支持举报
- 支持后台禁言

第一版限制：

- 只支持文字聊天。
- 案例区优先由官方运营。
- 不做复杂社交关系。

首页围绕“今天拍什么”设计。

核心区域：

流程：

## 9. 验收标准

### 9.1 登录与账号

- 用户可以使用微信登录进入 App。
- 用户可以使用手机号验证码登录。
- 微信登录后能获取授权昵称、头像和微信身份标识。
- 用户可以修改对外显示名。
- 每个用户登录后自动拥有独立数据空间。
- 不同用户之间的数据互相隔离。

### 9.2 IP 档案与 RAG

- 用户可以创建和修改老板 IP 档案。
- 用户可以录入行业、产品、客户、老板经历、品牌故事、案例、常见问题等信息。
- 用户可以手动添加素材。
- 用户可以上传文档素材。
- 用户可以上传产品图片。
- AI 生成文案时能够检索并引用用户自己的素材。
- AI 生成文案时能够参考用户选择的产品图片。
- 用户可以看到文案参考了哪些素材和图片。

### 9.3 AI 文案生成

- 用户输入主题后，系统能生成可直接拍摄的口播稿。
- 文案默认参考爆款视频文案结构。
- 文案默认结合用户自己的 RAG 素材库。
- 文案默认结合用户选择的产品图片。
- 用户可以选择视频时长、平台和表达风格。

- 用户可以重新生成、局部改写、缩短、扩写。

- 用户可以在手机竖屏模式下拍摄。

## 10. 技术实现建议

### 10.1 移动端

第一版建议做原生移动 App，优先覆盖 iOS 和 Android。

可选方案：

- Flutter：跨平台效率高，适合快速落地。
- React Native：生态较好，但视频拍摄和美颜能力需要重点验证。
- 原生 iOS + Android：体验最好，开发成本最高。

建议：

- 预算有限时优先 Flutter。
- 如果拍摄体验要求极高，优先原生开发。

### 10.2 后端

后端模块：

- 用户与登录服务
- 多租户数据隔离服务
- IP 档案服务
- RAG 素材库服务
- 产品图片理解服务
- AI 文案生成服务
- 视频剪辑任务服务
- 成片模板服务
- 发布任务服务
- 实时聊天服务
- 内容审核服务

### 10.3 RAG 与多模态生成

生成链路：

用户输入主题 -> 检索 RAG 知识库 -> 分析产品图片 -> 匹配爆款模板 -> 生成口播稿 -> 标记重点句 -> 返回可编辑脚本

关键要求：

- 每个租户数据强隔离。
- 产品图片先做视觉理解和 OCR，再转成结构化素材。
- 爆款模板只参考结构，不复制原文。
- 每次生成记录引用素材，便于追溯。

### 10.4 视频剪辑

建议云端处理为主，本地处理为辅。

剪辑流程：

1. 拍摄完成后本地预览。
2. 用户确认使用。
3. App 自动创建剪辑任务。
4. 视频自动进入本地或云端处理队列。
5. 系统处理语音识别、停顿检测、口气词识别、字幕、黄字、BGM、Logo、水印、片头、片尾。
6. App 通过任务状态接口或 WebSocket 获取进度。
7. 成片完成后返回预览地址。

### 10.5 发布

发布采用双模式：

- API 直发模式：平台允许时授权发布。
- 发布助手模式：平台受限时，保存视频、复制文案和话题、跳转对应 App。

## 11. 主要风险

高优先级风险：

- 拍摄中前后摄像头切换不断录音。
- 透明提词层与视频录制稳定性。
- 自动剪辑速度和云端成本。
- 语音识别、去口气词、去停顿准确率。
- 平台一键发布能力限制。
- RAG 多租户数据隔离。
- 产品图片理解是否真正提升文案质量。
- 聊天社区内容审核。
- 用户上传 BGM 的版权风险。

建议优先验证：

1. AI 文案生成。
2. 透明提词拍摄。
3. 拍摄后自动进入剪辑。
4. 剪辑进度展示。
5. 成片预览。
6. 发布助手。

## 12. 第一版成功标准

AI-IP 第一版成功的标准不是功能多，而是核心闭环顺畅：

用户能在 App 内完成：

1. 登录。
2. 建立自己的老板 IP 档案。
3. 上传业务素材和产品图片。
4. 输入主题生成口播文案。
5. 手动修改文案。
6. 用透明提词拍摄。
7. 拍完确认后自动剪辑。
8. 看到剪辑进度。
9. 预览并调整成片。
10. 发布到短视频平台。

如果一个老板可以用 AI-IP 每天稳定完成 1 条可发布口播视频，第一版目标即达成。
